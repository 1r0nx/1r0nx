### 🔐 Crypto & encodings
| Project | Description |
|---|---|
| [**shatter**](https://github.com/1r0nx/shatter) | RSA attack toolkit |
| [**aletheia**](https://github.com/1r0nx/aletheia) | Decodes or brute-forces common ciphers |
